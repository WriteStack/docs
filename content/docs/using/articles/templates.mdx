---
title: Article templates
description: How to save part of an article as a reusable template, insert it into any article from the Template menu or the / menu, edit, rename and delete templates.
---

A template is a piece of an article you reuse, like a weekly intro, a sign-off with a Subscribe button, or a section layout. You insert it into any article where your cursor is. Templates hold only body content, not a title or settings.

## Make a template

1. In an article, select the part you want to reuse. Skip this to start blank.
2. Click **Template → New template** in the toolbar.
3. The template editor opens with what you selected. Give it a name (up to 120 characters).
4. Edit it like an article. It saves on its own.
5. Close it with the ✕ or Esc.

A template can hold every block the article editor has, except audio. If you have more than one newsletter, **Made for newsletter** picks which one button captions and videos use. The template still works in any newsletter.

## Insert a template

1. Put your cursor where it should go.
2. Click **Template** in the toolbar and pick it, or type `/` and the template's name.

If the template has a freewall or paywall, the article's **Audience** changes to match, the same as inserting the wall yourself.

## Edit, rename or delete

Open **Template** in the toolbar and hover a template:

- The pencil opens it to edit. Rename it in the name field at the top.
- The trash deletes it. Articles where you already inserted it stay as they are.

Changing a template doesn't change articles you already inserted it into.

## Limits

| Item | Limit |
| --- | --- |
| Template name | 120 characters |
| Image size | 15 MB |
| Number of templates | No limit |

Templates are only in the app. The Coach and AI agents can't use them yet.

## If it doesn't work

| Message | Fix |
| --- | --- |
| "No templates yet" | Make one with **New template**. |
| "This template doesn't exist anymore." | It was deleted, maybe in another tab. |
| "This template changed elsewhere" | Pick **Reload** or **Keep mine**. |
| "Failed to create the template." | You need a connected newsletter. See [Connect Substack](/docs/using/setup/connect-substack). |
