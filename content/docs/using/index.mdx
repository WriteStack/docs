## The main loop

| Step | What you do | Where |
| --- | --- | --- |
| 1. Draft | Write a Note yourself, or have WriteStack draft it in your saved writing style. | **My Notes → New note** |
| 2. Queue | Add the Note to your queue. It takes the next free time on your weekly schedule. | Note editor → **Add to Queue** |
| 3. Sync | The browser extension schedules the Note on Substack. Substack publishes it at its time. | **My Notes → Scheduled notes** |
| 4. Measure | See impressions, engagement and new subscribers for each published Note. | **Notes Performance** |

The queue lives in WriteStack. A Note only reaches Substack once it is synced. Read [Sync](/docs/using/concepts/sync) to understand when that happens on its own and when you need to click the yellow button.
